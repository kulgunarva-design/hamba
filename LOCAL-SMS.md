# Локальная запись с SMS

Запуск: откройте START.cmd (нужен Node.js 22 или новее), затем http://localhost:3000.
Остановка: Ctrl+C в окне сервера. Не открывайте HTML двойным щелчком для проверки отправки.

По умолчанию включён тестовый режим: форма показывает текст будущего SMS, но ничего не отправляет и не сохраняет. Получатель зафиксирован на сервере: +37253911527. Переведены сообщения формы на русский, эстонский и английский. Комментарий убран из формы; SMS содержит только имя, телефон и день.

Для настоящей отправки скопируйте .env.example в .env, заполните TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN и TWILIO_FROM из своего аккаунта Twilio, выставьте SMS_MODE=live и перезапустите сервер. TWILIO_FROM — отправитель, разрешённый в вашем аккаунте, а не номер получателя. Подключение аккаунта, оплата и реальная доставка ещё не проверены. Не присылайте секреты в чат и не загружайте .env в GitHub. API: https://www.twilio.com/docs/messaging/api/message-resource

При тестовом аккаунте Twilio номер получателя нужно подтвердить в аккаунте. Нужны разрешённая отправка в Эстонию и подходящий отправитель. SMS оплачиваются по тарифам сервиса. Успешный ответ означает принятие SMS сервисом, а не подтверждённую доставку или запись к врачу.

Сервер слушает только локальный компьютер. В live-режиме разрешено до пяти попыток отправки в час на процесс. Автоматического повтора при сбое нет: при неопределённом результате проверьте сообщения в панели SMS-сервиса перед повтором.

GitHub Pages размещает статические страницы и не запускает server.mjs. Для публикации понадобится отдельный HTTPS-обработчик: перенести SMS-логику туда, задать адрес API во фронтенде, разрешить только домен сайта и добавить постоянное ограничение запросов, защиту от автоматических заявок и повторов. Текущая версия предназначена для локальной проверки, не для публичного SMS API. Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
